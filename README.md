# Reverse Loop

一款使用 Unity 开发的 2D 时间回溯解谜平台游戏。玩家的移动轨迹会被记录，并在时间回溯后生成沿历史路径行动的敌对影子。玩家需要利用平台移动与跳跃能力，同时避开自己的过去，到达关卡终点。

本项目作为 Game Jam 原型开发，仓库名保留为 `TencentGameJam`。

## 核心玩法

- 控制角色在 2D 平台关卡中移动和跳跃
- 实时记录玩家经过的位置并绘制移动轨迹
- 触发时间回溯，使玩家沿记录路径逆向移动
- 在回溯结束后生成重演历史路径的敌对影子
- 规划新的行动路线，避免与过去的自己发生碰撞
- 到达目标区域后推进关卡流程

## 技术栈

- Unity `2022.3.42f1c1`
- C#
- Universal Render Pipeline
- Unity 2D Physics
- UGUI
- Line Renderer
- Animator

## 核心系统

### 时间回溯状态机

`Recall` 使用 `Before`、`StartRecall`、`Recall` 和 `After` 四个状态管理完整的时间流程，将正常行动、回溯触发、逆向移动和影子生成拆分为清晰阶段。

### 轨迹记录与逆向播放

角色移动期间持续采样世界坐标，并使用 `LineRenderer` 显示行动轨迹。回溯开始后，系统按照相反顺序读取记录点，使角色沿历史路径返回。

### 历史影子系统

回溯结束后，系统生成敌对影子并复用玩家的历史轨迹。`EnemyFollow` 从距离当前位置最近的轨迹点开始移动，根据路径方向更新朝向和动画，并在完成一次重演后进入队列等待再次启用。

### 2D 角色控制

`Movement` 负责横向输入、角色翻转、动画切换和跳跃。`CheckPhysics` 使用向下及多角度射线检测地面，根据跳跃状态计算重力和垂直速度，以适应不同平台边缘。

### 游戏流程与反馈

项目实现了异步场景加载、暂停与继续、越界重置、常驻背景音乐和结局跳转。时间回溯过程结合轨迹显示、遮罩、音效与相机震动，强化状态切换反馈。

## 项目结构

```text
Assets/
├── Prefabs/               角色与场景预制体
├── Scenes/                游戏场景
├── Scripts/
│   ├── Recall.cs          时间回溯状态机
│   ├── PlayerTrail.cs     玩家轨迹采样
│   ├── EnemyFollow.cs     历史影子路径重演
│   ├── Movement.cs        角色移动与动画
│   ├── CheckPhysics.cs    重力、跳跃与地面检测
│   ├── ShakeCamera.cs     相机震动反馈
│   └── Uimanager.cs       UI 与异步场景流程
├── Settings/              URP 渲染配置
├── Sprites/               2D 美术资源
└── Tile/                  关卡 Tile 资源
```

## 运行项目

1. 安装 Unity Hub。
2. 使用 Unity `2022.3.42f1c1` 打开仓库目录。
3. 等待 Package Manager 完成依赖导入。
4. 在 `Assets/Scenes` 中打开起始场景。
5. 进入 Play Mode 运行游戏。
